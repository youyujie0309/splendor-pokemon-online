# 《璀璨宝石：宝可梦》好友联机版 (Splendor: Pokémon Online)

专为好友实时联机与**中文互联网直连**打造的《璀璨宝石：宝可梦》网页版桌游，手机竖屏优先适配，无广告、无需注册、打开链接即可开玩。

## 核心特色

- **完整 90 张关都地区原版卡组**：
  - Lv.1（35 张） / Lv.2（30 张） / Lv.3（15 张） + 稀有宝可梦（5 张） + 传说/幻之宝可梦（5 张）。
  - 完整还原 **5 种基础精灵球（精灵球/超级球/先机球/治愈球/高级球）+ 万能大师球**、**10 球上限弃置**、**免费进化机制**（仅计永久图标，进化后替换原卡）、**稀有与传说卡不可预留且必须消耗大师球**、**18 分触发最后一轮** 与平局判定规则。
- **零外部 CDN 依赖（国内秒开）**：
  - 全部 90 张高清宝可梦官方立绘已预先压缩为 WebP（总计仅约 1.2 MB）并内置于 `public/assets/pokemon/`。
  - 无 Google Fonts、无海外图床、无外部 JS CDN，部署在国内节点即可实现微信/手机浏览器直连秒开。
- **实时 WebSocket 联机 + 断线自动重连**：
  - 基于 Node.js + Express + Socket.IO（支持 WebSocket 与长轮询自动降级，兼容微信内置浏览器与弱网环境）。
  - 公开房间大厅、6 位数字房间号加入、**一键复制邀请链接**（`?room=房间号` 点开直达）、切屏/刷新自动重连回原座位。
  - 支持 **2–4 人联机**、**AI 机器人补位 / 单机练习**、可选回合倒计时（不限时/30秒/60秒）与快捷发言。

## 本地运行

```bash
npm install
npm start
```

默认监听 `http://0.0.0.0:3000`。

## 国内互联网直连部署指南

本应用为**单进程 Node.js 服务**（静态页面 + 90 张本地立绘 + WebSocket 合一），部署极其简单：

### 方案 A：Docker 一键部署（推荐：腾讯云轻量 / 阿里云 ECS 等国内服务器）

```bash
docker compose up -d --build
```

部署后放行 `3000` 端口（或用 Nginx / Caddy 反代并配置 HTTPS），把域名发给朋友即可直接联机。

> 若使用 Nginx 反向代理，记得开启 WebSocket 升级头：
> ```nginx
> location / {
>     proxy_pass http://127.0.0.1:3000;
>     proxy_http_version 1.1;
>     proxy_set_header Upgrade $http_upgrade;
>     proxy_set_header Connection "upgrade";
>     proxy_set_header Host $host;
> }
> ```

### 方案 B：国内容器云一键上线（Sealos / Zeabur 等）

1. 将本项目推送到你的 Git 仓库（Gitee / GitHub）。
2. 在 **Sealos（国内有北京/杭州等节点，自带公网 HTTPS 域名，免备案直连）** 或 **Zeabur** 中新建应用，选择 Dockerfile 部署，暴露端口 `3000`。
3. 部署完成后打开平台分配的 HTTPS 链接，创建房间并把邀请链接发到微信群即可开玩！

### 方案 C：零成本临时和朋友联机（在自己电脑跑 + 内网穿透）

如果你不想买服务器，只需在自己电脑运行 `npm start`，再用国内直连穿透工具（如 **cpolar / 樱花 Frp / natapp**）把本机 `3000` 端口映射出一个公网地址发给朋友即可。
